# Приложение проверяющего на входе

Приложение проверяющего нужно для сканирования QR-кодов билетов на входе.

## Как работает проверка

1. Бот продает билеты и выдает QR.
2. Админ после завершения продаж делает `/export`.
3. Бот присылает JSON-файл со всеми оплаченными и бесплатными билетами.
4. Проверяющий импортирует этот JSON в Android-приложение.
5. На входе проверяющий сканирует QR.
6. Приложение показывает:
   - `ПРОПУСТИТЬ` - билет найден и еще не использовался;
   - `УЖЕ ИСПОЛЬЗОВАН` - этот QR уже сканировали на этом телефоне;
   - `НЕ НАЙДЕН` - QR отсутствует в импортированной базе.

## Одноразовость QR

После успешного сканирования приложение сохраняет код как использованный локально на телефоне. Второй раз этот же QR не пройдет.

Если используется несколько телефонов, каждый телефон хранит свои отметки отдельно. Для строгой проверки на нескольких входах нужна онлайн-синхронизация через сервер или организационное разделение потоков.

## Как собрать APK

На компьютере должен быть установлен Android Studio с Android SDK.

Запуск сборки:

```text
BUILD_VALIDATOR_APK_WINDOWS.bat
```

Скрипт скачает Gradle, соберет debug APK и положит его сюда:

```text
dist\qr-ticket-validator-debug.apk
```

Если Android SDK не найден, откройте папку `validator_app` в Android Studio и нажмите `Build > Build APK(s)`.

## Как пользоваться APK

1. Установить APK на Android-телефон.
2. Получить JSON-файл от команды `/export`.
3. Передать JSON на телефон.
4. Открыть приложение.
5. Нажать `Импорт базы JSON`.
6. Выбрать JSON-файл.
7. Нажать `Сканировать QR`.

Кнопка `Сбросить отметки прохода` очищает только отметки использованных QR на телефоне. Сама база билетов остается.
